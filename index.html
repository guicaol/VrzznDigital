Como usar o VrzzN

Um oráculo simples para jogar sozinho ou para destravar a mesa.

Os dois dados

Neste oráculo, você joga com 2 dados de 6 lados (D6), de cores diferentes:

  • 1 dado para resposta
  • 1 dado para evento

Faça uma pergunta de sim ou não e role os dados.

  • 1–3 = Não
  • 4–6 = Sim

Se os dois dados mostrarem o mesmo número, ocorre um evento. Role na tabela de eventos (D66).

Como rolar D66

  • primeiro dado = dezena
  • segundo dado = unidade

Exemplo: resultado 3 e 5 = 35.

Exemplo

Você está diante de uma casa isolada.

Pergunta: Essa casa parece abandonada?

Resultado: dado resposta = 2, dado evento = 3.

Resposta: Não.

Como os números são diferentes, nenhum evento acontece. Porém, se fosse, por exemplo, 2 e 2, um evento seria ativado.

Dica

Se tiver dúvida, pergunte ao oráculo. Se quiser ideias ou descrições, use a tabela de palavras aleatórias.
